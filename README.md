# Personal Portfolio Website 🌐

This is a fully responsive personal website built using **HTML**, **CSS**, and **JavaScript**. It showcases your skills, projects, resume, and contact information — ideal for developers and designers looking to establish an online presence.

## 🌟 Features

- Clean, responsive design
- About Me section
- Skills showcase
- Portfolio/projects section with links
- Resume download button
- Contact form (static or functional via email services)
- Smooth scroll and animations
- Mobile-friendly layout

## 🛠 Tech Stack

- **HTML5** – Markup
- **CSS3** – Styling & responsiveness
- **JavaScript (Vanilla)** – Interactivity and animations
- **Fonts & Icons** – Google Fonts, Font Awesome (optional)
